# Quiz App 🚀

A simple and interactive JavaScript Quiz Application built using HTML, CSS, Bootstrap, and JavaScript. The app presents multiple-choice questions, tracks the user's score, includes a countdown timer for each question, and displays a detailed review summary at the end.

## 🌐 Live Demo

🔗 **Netlify Live Link:** https://lighthearted-fudge-42e2e1.netlify.app/

## 📸 Features

* ✅ Multiple-choice quiz questions
* ✅ 30-second timer for each question
* ✅ Automatic next question when time expires
* ✅ Instant answer selection
* ✅ Score calculation
* ✅ Detailed result summary
* ✅ Displays correct and selected answers
* ✅ Responsive UI with Bootstrap 5

## 🛠️ Technologies Used

* CSS3
* JavaScript (ES6)

## 🎮 How It Works

1. The quiz starts with Question 1.
2. Users select one of the available options.
3. Each question has a 30-second timer.
4. If the timer reaches zero, the question is marked as unanswered.
5. After all questions are completed, the final score is displayed.
6. Users can review all questions along with their answers and the correct answers.
